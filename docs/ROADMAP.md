# Eagle Bot Roadmap

## Phase 1 — Foundation
Identity, persistence boundary, configuration, security baseline, health and audit.

## Phase 2 — Intelligence
Orchestration, durable memory, AI gateway, evidence handling and world-information providers.

## Phase 3 — Coworkers
Generalist, Researcher, Builder, Analyst, Operator and Educator implementations with evaluations.

## Phase 4 — Governance
Permissions, risk classification, approvals, human-in-the-loop controls and emergency procedures.

## Phase 5 — Channels
Web first, Telegram bridge, then API/mobile channels.

## Phase 6 — Real Work
Tasks, orders, projects, files, workflows, tools and outcome tracking.

## Phase 7 — Scale
PostgreSQL, observability, backups, rate limiting, tenant isolation and global infrastructure where justified.

### Rule
A roadmap item is not an implemented capability until code, tests and operational evidence exist.
